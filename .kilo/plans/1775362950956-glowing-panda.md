# Plan : Système de Calques — v1.3.0

## Contexte
Le fichier `V1/test/BABIQUES-HSW-GENERATOR-v1.2.2.html` contient l'application complète (~4000 lignes). Chaque pièce est stockée dans `elements` (Map) et `elementTypes` (Map) avec des clés `slotKey(q, r, slot)`. Le système de calques doit s'intégrer sans casser les fonctionnalités existantes (placement, suppression, undo/redo, miroir, bordures, export, session).

### JavaScript — Fonctions du Panneau Calques

#### `renderLayersList()`
- Vide `#layers-list`
- Trie les calques par `order` décroissant
- Pour chaque calque, crée une `layer-row` avec :
  - Poignée drag (⠿)
  - Œil (toggle `visible`) → appelle `setLayerVisibility(id, bool)`
  - Cadenas (toggle `locked`) → appelle `setLayerLocked(id, bool)`
  - Carré couleur → ouvre `<input type="color">` → appelle `setLayerColor(id, hex)`
  - Nom (double-clic → input éditable) → appelle `setLayerName(id, name)`
  - Clic droit → menu contextuel (Dupliquer, Fusionner, Supprimer)
  - Clic simple → `setActiveLayer(id)`
- Marque le calque actif avec classe `.active`

#### `createLayer(name, color, order)`
- Génère `layer_${nextLayerId++}`
- Ajoute à `layers`
- Met à jour `order` des calques existants si besoin
- Appelle `renderLayersList()`
- Retourne l'ID

#### `deleteLayer(layerId)`
- Si 'default', ignorer
- Déplacer toutes les pièces vers 'default' :
  ```js
  for (const [sk, lid] of pieceToLayer) {
      if (lid === layerId) pieceToLayer.set(sk, 'default');
      applyLayerColorToPiece(sk, 'default');
  }
  ```
- `layers.delete(layerId)`
- Si `activeLayerId === layerId`, `activeLayerId = 'default'`
- `renderLayersList()`

#### `duplicateLayer(layerId)`
- Créer nouveau calque avec nom `${name} (copie)`
- Copier toutes les pièces :
  ```js
  for (const [sk, lid] of pieceToLayer) {
      if (lid === layerId) pieceToLayer.set(sk, newId);
  }
  ```
- Appliquer couleur du nouveau calque

#### `mergeLayers(sourceId, targetId)`
- Déplacer toutes les pièces de source vers cible
- `layers.delete(sourceId)`
- Si `activeLayerId === sourceId`, `activeLayerId = targetId`
- Appliquer couleur du calque cible

#### `groupSelectedPieces()`
- Si `selectedPieces.size < 2`, ignorer
- Créer nouveau calque
- Pour chaque sk dans `selectedPieces` :
  ```js
  const oldLid = pieceToLayer.get(sk);
  pieceToLayer.set(sk, newId);
  applyLayerColorToPiece(sk, newId);
  ```
- `selectedPieces.clear()`
- `activeLayerId = newId`
- `renderLayersList()`

#### `setActiveLayer(id)`
- `activeLayerId = id`
- Mettre à jour highlights sur les rows
- Mettre à jour `selectedPieces` avec les pièces du calque
- Highlight visuel des pièces

#### `setLayerVisibility(id, visible)`
- `layers.get(id).visible = visible`
- Pour chaque pièce du calque : `mesh.visible = visible`
- `renderLayersList()`

#### `setLayerLocked(id, locked)`
- `layers.get(id).locked = locked`
- `renderLayersList()`

#### `setLayerColor(id, hex)`
- `layers.get(id).color.set(hex)`
- Pour chaque pièce : `mesh.material.emissive.set(hex)` et `mesh.material.color.set(hex)`
- `renderLayersList()`

#### `setLayerName(id, name)`
- `layers.get(id).name = name`
- `renderLayersList()`

#### `applyLayerColorToPiece(sk, layerId)`
- Récupère le mesh et la couleur du calque
- Applique au matériau

#### `applyLayerVisibilityToPiece(sk, layerId)`
- Récupère le mesh et la visibilité du calque
- Applique `mesh.visible`

### Highlight de Sélection
```js
function highlightPiece(sk, highlight) {
    const mesh = elements.get(sk);
    if (!mesh) return;
    if (highlight) {
        mesh.userData.origColor = mesh.material.color.getHex();
        mesh.userData.origEmissive = mesh.material.emissive.getHex();
        mesh.material.color.set(0xffffff);
        mesh.material.emissive.set(0xffffff);
        mesh.material.emissiveIntensity = 0.25;
    } else {
        const lid = pieceToLayer.get(sk);
        if (lid && layers.has(lid)) {
            const col = layers.get(lid).color;
            mesh.material.color.set(col);
            mesh.material.emissive.set(col);
            mesh.material.emissiveIntensity = 0.04;
        }
    }
}
```

### Drag de Pièces Sélectionnées (Déplacement Groupé)
- Dans `mousemove` : si `selectedPieces.size > 0` et drag détecté :
  - Calculer offset depuis `mouseStart`
  - Pour chaque sk dans `selectedPieces` :
    - Vérifier que le calque n'est pas locked
    - Calculer nouvelle position
    - Supprimer l'ancienne pièce, recréer à la nouvelle position (via `removeSlot` + `placeElement`)
  - Mettre à jour `pieceToLayer`
- Cette fonctionnalité est complexe car le système actuel est basé sur la grille hexagonale. Le déplacement groupé doit :
  1. Calculer le delta de cellules (dq, dr) pour chaque pièce
  2. Vérifier les overlaps pour toutes les nouvelles positions
  3. Supprimer les anciennes, placer les nouvelles
  4. Conserver les calques

### Modification de `markThreatenedAt()` et `overlapAreaBetween()`
- Prendre en compte les calques locked : ne pas marquer comme threatened les pièces d'un calque locked (elles ne peuvent pas être déplacées)

### Modification de `paintAt()` et `eraseAt()`
- Vérifier `layers.get(activeLayerId).locked` avant de peindre
- Vérifier `layers.get(pieceToLayer.get(sk)).locked` avant d'effacer

### Drag & Drop Hex Grid — Approche Simplifiée (v1.3.0)
Le déplacement groupé de pièces sur la grille hexagonale est complexe. Pour v1.3.0 :
- **Ne pas implémenter** le drag de pièces sélectionnées sur la grille
- À la place : le "Grouper" crée un calque, l'utilisateur peut masquer/déplacer individuellement
- **Alternative future (v1.4.0)** : déplacement par Ctrl+flèches ou outil dédié

### Menu Contextuel — Positionnement
- Utiliser `position: fixed` plutôt que `absolute` pour éviter les problèmes de overflow du sidebar
- Calculer la position depuis `e.clientX` / `e.clientY`
- Fermer au clic ailleurs : `window.addEventListener('click', () => ctxMenu?.remove())`

### Compatibilité AZERTY
- Le code actuel gère déjà `e.key === 'z' || e.key === 'Z'` pour Ctrl+Z (ligne 2840)
- Le Shift+clic pour multi-select fonctionne indépendamment de la disposition clavier

### Performance — Batch Updates
Pour la visibilité et la couleur, itérer sur `pieceToLayer` plutôt que `elements` :
```js
function applyLayerVisibility(id) {
    const layer = layers.get(id);
    if (!layer) return;
    for (const [sk, lid] of pieceToLayer) {
        if (lid === id) {
            const mesh = elements.get(sk);
            if (mesh) mesh.visible = layer.visible;
        }
    }
}
```

### Cas Limites à Gérer
1. **Suppression du dernier calque** : empêcher, toujours garder au moins 'default'
2. **Import JSON ancien format** (sans calques) : assigner toutes les pièces au calque 'default'
3. **Pièce orpheline** (sk dans `pieceToLayer` mais pas dans `elements`) : nettoyer au chargement
4. **Calque vide** : autorisé, affiché avec compteur de pièces à 0
5. **Nom de calque vide** : fallback à `Calque N`
6. **Couleur invalide** : fallback à la couleur par défaut du calque

        // Vérifier si toutes nouvelles positions sont valides

            const nq = gmesh.userData.q + dq;

            if (!canPlace(nq, nr, elementTypes.get(gsk))) {
                canMove = false;
                break;
            }
        }
        if (canMove) {

            for (const gsk of dragGroupPieces) {
                const gmesh = elements.get(gsk);
                if (!gmesh) continue;

                // Remove old
                removeSlot(gsk);
                // Place new
                const type = elementTypes.get(gsk);
                placeElement(nq, nr, type);
                // Record action
                recordMoveAction(gsk, oldQ, oldR, nq, nr);
            }
            dragStartPos = { q: newCell.q, r: newCell.r };
        }
    }
}
