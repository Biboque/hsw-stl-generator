# Plan : Amélioration Calques, Déplacement de Groupe et Surbrillance

## Contexte

Fichier cible : `V1/test/BABIQUES-HSW-GENERATOR-v1.3.1.html` (~5092 lignes)

Architecture actuelle :
- **Calques** : `layers` Map (id → {name, visible, locked, order, color}) + `pieceToLayer` Map (slotKey → layerId)
- **Sélection** : `selectedPieces` Set de slotKeys, surbrillance blanche via `highlightSinglePiece()` (color/emissive → 0xffffff)
- **Déplacement groupe** : `activeTool === 'moveGroup'` + `isDraggingGroup`, mais OrbitControls n'est pas désactivé pendant le drag
- **Bouton "Nouveau"** : crée un calque vide, n'utilise pas les pièces sélectionnées
- **Bouton "Grouper"** : crée un nouveau calque ET y déplace les pièces sélectionnées (nécessite ≥2 pièces)

## Problèmes à résoudre

1. **"Nouveau calque"** ne prend pas en compte les pièces sélectionnées — il crée toujours un calque vide
2. **Pas de moyen de déplacer la sélection vers un calque existant** — seul le bouton "Grouper" crée un nouveau calque
3. **OrbitControls n'est pas désactivé** pendant le drag de groupe → la vue bouge au lieu du groupe
4. **Surbrillance blanche** masque les pièces sélectionnées — besoin d'un contour jaune semi-transparent

el.addEventListener('mousedown', e => {

## Phase 3 : Remplacer la surbrillance blanche par contour jaune + overlay semi-transparent

### 3.1 Approche retenue : Double effet — Contour EdgesGeometry + Overlay Mesh

Au lieu de changer la couleur du matériau (qui masque la pièce), on ajoute DEUX éléments :
1. **Contour** : `THREE.LineSegments` avec `THREE.EdgesGeometry` — outline jaune autour de la pièce
2. **Overlay** : Un mesh dupliqué légèrement plus grand avec un matériau jaune semi-transparent

### 3.2 Nouvelle structure de données

Ajouter une Map pour tracker les surbrillances :

```js
// Après la déclaration de selectedPieces (~ligne 2419)
const selectionHighlights = new Map(); // slotKey → { outline: LineSegments, overlay: Mesh }
```

### 3.3 Nouvelle fonction `highlightSinglePiece(sk)`

**Fichier** : ~ligne 3922

**Remplacer** la fonction actuelle par :

```js
function highlightSinglePiece(sk) {
    if (selectionHighlights.has(sk)) return; // déjà highlight
    const mesh = elements.get(sk);
    if (!mesh) return;
    const geo = mesh.geometry;
    if (!geo) return;

    // 1. Contour (EdgesGeometry + LineSegments)
    const edgesGeo = new THREE.EdgesGeometry(geo);
    const lineMat = new THREE.LineBasicMaterial({ color: 0xffdd00, transparent: true, opacity: 0.9 });
    const outline = new THREE.LineSegments(edgesGeo, lineMat);
    outline.position.copy(mesh.position);
    outline.rotation.copy(mesh.rotation);
    outline.scale.copy(mesh.scale).multiplyScalar(1.02);
    outline.renderOrder = 999;
    scene.add(outline);

    // 2. Overlay (mesh dupliqué semi-transparent jaune)
    const overlayMat = new THREE.MeshBasicMaterial({
        color: 0xffdd00,
        transparent: true,
        opacity: 0.15,
        depthWrite: false,
        side: THREE.DoubleSide
    });
    const overlay = new THREE.Mesh(geo, overlayMat);
    overlay.position.copy(mesh.position);
    overlay.position.z += 0.5; // légèrement au-dessus
    overlay.rotation.copy(mesh.rotation);
    overlay.scale.copy(mesh.scale).multiplyScalar(1.01);
    overlay.renderOrder = 998;
    scene.add(overlay);

    selectionHighlights.set(sk, { outline, overlay });
}
```

### 3.4 Nouvelle fonction `clearPieceHighlight(sk)`

```js
function clearPieceHighlight(sk) {
    const hl = selectionHighlights.get(sk);
    if (!hl) return;
    // Contour
    scene.remove(hl.outline);
    hl.outline.geometry.dispose();
    hl.outline.material.dispose();
    // Overlay
    scene.remove(hl.overlay);
    hl.overlay.geometry.dispose();
    hl.overlay.material.dispose();
    selectionHighlights.delete(sk);
}
```

### 3.5 Nouvelle fonction `clearAllHighlights()`

```js
function clearAllHighlights() {
    for (const [, hl] of selectionHighlights) {
        scene.remove(hl.outline);
        hl.outline.geometry.dispose();
        hl.outline.material.dispose();
        scene.remove(hl.overlay);
        hl.overlay.geometry.dispose();
        hl.overlay.material.dispose();
    }
    selectionHighlights.clear();
}
```

## Phase 4 : Tests et validation

### 4.1 Tests manuels recommandés

1. **Sélection → Nouveau calque** : Sélectionner des pièces (Shift+clic ou outil Sélection), cliquer "Nouveau" → vérifier qu'un nouveau calque est créé ET que les pièces y sont déplacées
2. **Sélection → Menu contextuel → Déplacer vers** : Sélectionner des pièces, clic droit sur un calque existant → "Déplacer la sélection ici" → vérifier le déplacement
3. **Undo/Redo** : Annuler/refaire les opérations ci-dessus (Ctrl+Z / Ctrl+Y)
4. **Déplacement de groupe** : Activer l'outil "Déplacer Groupe", cliquer sur une pièce sélectionnée et drag → vérifier que le groupe bouge et que la vue reste fixe
5. **Surbrillance combinée** : Sélectionner des pièces → vérifier le contour jaune ET l'overlay semi-transparent, la pièce originale reste visible avec sa couleur
6. **Nettoyage** : Supprimer une pièce sélectionnée → vérifier que contour ET overlay disparaissent
7. **Group move avec surbrillance** : Déplacer un groupe → vérifier que les surbrillances suivent les pièces

### 4.2 Vérifications

- Pas de fuite mémoire (dispose des geometries/materials des outlines ET overlays)
- Les surbrillances suivent correctement les pièces lors des déplacements
- OrbitControls est correctement désactivé pendant le drag et réactivé après
- Le compteur de pièces par calque est correct après déplacement
- `renderOrder` garantit que les overlays/contours sont toujours au-dessus des pièces
